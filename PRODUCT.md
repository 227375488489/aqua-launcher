# PRODUCT.md - Aqua Launcher 0.0.8 Beta

**Ваш мир. Без лишних шагов.** Aqua Launcher — десктопный лаунчер Minecraft: Java Edition для Windows, macOS и Linux на Rust.

## Продукт

- Платформы: Windows 10/11, macOS 10.15+, Linux (x64/ARM64).
- Стек: Rust (вся логика) + Tauri 2 + собственный CSS/JS без фреймворков и сборщика.
- Языки интерфейса: 12 (ru, uk, en, kk, pl, cs, sk, fr, de, it, es, pt) + автоопределение.
- Окно 1280×820, кастомный заголовок; на macOS — нативные кнопки окна и overlay-titlebar.

## Для кого

Игрок, который хочет запустить любую версию, поставить моды или готовую сборку и не думать о Java, библиотеках и папках. Опытный игрок получает профили, JVM-аргументы и статистику; новичок — одну большую кнопку.

## Jobs to be done

1. Запустить любую версию из манифеста Mojang — от альфы до свежего релиза.
2. Поставить мод, ресурспак или шейдер с Modrinth вместе с зависимостями.
3. Установить сборку `.mrpack` в отдельный профиль и играть, не смешивая моды.
4. Войти офлайн по нику или через Microsoft по device-code.
5. Настроить лаунчер под себя: раскладку, виджеты, тему, обои, язык.
6. Посмотреть, сколько времени в игре, и подобрать настройки под свой ПК.

## Что делает продукт особенным

- Все версии Minecraft и честные официальные источники: Mojang, Modrinth, Adoptium.
- Профили: у каждой сборки свои моды, конфиги и миры.
- Интерфейс собирается пользователем: порядок разделов и виджетов, позиция кнопки, темы, обои.
- 12 языков с корректными числами, датами и склонениями через `Intl`.
- Скорость: потоковые загрузки, параллельность, кеш, проверка SHA-1, Rust без Electron.
- Вода как характер: глубокий океан, стекло, мягкая аврора — без потери читаемости.

## Тон

Спокойный, точный, без сленга и без «✨». Короткие подписи, честные статусы, ошибки объясняют, что делать.

## Границы

- Загрузчики модов — Fabric, Forge и NeoForge. Quilt-сборки не устанавливаются: об этом сообщается заранее.
- Бета 0.1: возможны ошибки; лаунчер не предлагает откатиться на старые 3.x-релизы.
- Microsoft-вход использует публичный client id; свой можно указать в настройках.
- Токены хранятся локально в открытом виде — это указано в README.
