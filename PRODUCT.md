# PRODUCT.md — Aqua Launcher

**Один экран, одна кнопка, ноль трения.** Aqua Launcher — десктопный лаунчер Minecraft для Windows, написанный на Rust.

## Продукт

- Платформа: Windows (x64), десктоп-приложение, окно 1180×760, кастомный заголовок.
- Стек: Rust (вся логика) + Tauri 2 + собственный CSS/JS интерфейс без фреймворков.
- Язык интерфейса: русский.

## Для кого

Игрок, который хочет запустить Minecraft в два клика — без Oracle-аккаунтов, без ручной возни с Java, без «скачайте JDK 8 с сайта».

## Jobs to be done

1. Увидеть список версий и нажать «Играть».
2. Войти в пиратский (offline) аккаунт по нику — за 5 секунд.
3. Войти через Microsoft и играть на официальных серверах — device-code, без браузерных редиректов.
4. Скачать любую версию с официальных серверов Mojang и не думать о библиотеках, assets и Java.
5. Починить всё в настройках: память, Java, папка игры, JVM-аргументы.

## Что делает продукт особенным

- Скорость: параллельные загрузки, кеш assets, хеш-проверка, мгновенный старт.
- Всё в Rust — один .exe, без Electron.
- Вода как характер: глубокий океан, стекло, каустика, пузыри — но без потери читаемости.
